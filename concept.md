появляется дропдаун с тэгами, пытается отсортировать по совпадению.
Пример:
пользователь выбрал искать по тэгам, в его строке появилось  tags:, оригинальное меню заменилось на список тэгов в алфавитном порядке (высотой в 6 тэгов). Он начал вводить "ar" - теперь в списке тэгов первыми показываются те, что начинаются на "ar", при клике строка автодополняется, при tab-e автодополняется первый тэг. после каждого тэга должна быть запятая, мы ищем только строки после запятой. т.е. если в поиск строке "tags: art, vill" - мы предлагаем тэги villian)

Edge Cases

❗ Создание
если имя пустое → ошибка
если имя уже есть → pop up, где предлагаем заменить старый файл новым, при ok заменяем, при отмена пользователь остается на странице создания объекта 
если нет прав → pop up- У вас нет прав, чтобы создавать файлы в данной директории. Свяжитесь с владельцем проекта, чтобы получить права. (профиль владельца).
❗ Удаление
удаление папки → if SHOW_DELETE_FOLDER_WARNING → pop up Это действие удалит все файлы внутри папки. Вы уверены? +галочка не показывать больше (при отметке  SHOW_DELETE_FOLDER_WARNING=0), кнопки ОК и отмена. на ОК удаляется всё внутри, на отмена не удаляется.
❗ Перемещение
нельзя переместить папку в саму себя
нельзя в дочернюю папку
❗ Буфер обмена
copy → вставляет копию
cut → перемещает
❗ Теги
Есои пользователь создает объект с тэгом, которого нет в существующей базе тэгов, он создается, и ему присваивается случайный цвет.
